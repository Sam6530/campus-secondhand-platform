# ABCD 初始化技能包

所有成员先完整阅读[共同大纲](共同大纲.md)、[协作协议](协作协议.md)、[文档格式规范](../docs/文档格式规范.md)及[提交要求对照](../docs/提交要求对照.md)，共同确定章节、图表、篇幅和分工，再读取本人的skill执行。

| 成员 | 入口 | 主要职责 |
|---|---|---|
| a | [req-a-spec/SKILL.md](req-a-spec/SKILL.md) | 项目概述与用户需求，来源和业务澄清；不兜底全组统稿 |
| b | [req-b-model/SKILL.md](req-b-model/SKILL.md) | 领域与数据、规则与权限、行为与状态及配套模型 |
| c | [req-c-prototype/SKILL.md](req-c-prototype/SKILL.md) | 交互接口、质量与验收、原型、质量报告、总证据索引及统一交付 |
| d | [req-d-verify/SKILL.md](req-d-verify/SKILL.md) | 基线与人机协作、独立审查复核及AI报告；本人章节交叉复核 |

## 使用

不要求特定agent工具或自动安装。工具能读取仓库文件时，直接指定上述相对路径；不能识别skill格式时，把对应文件作为初始化上下文。单独复制一个角色目录时，要同时提供共用大纲、协议及格式规范。

可向agent发送：

> 项目是校园二手交易与物品流转平台。先读skills/共同大纲.md、skills/协作协议.md、docs/文档格式规范.md及本角色SKILL.md。检查已有共同决定，没有决定的部分先提出讨论事项。资料按本轮实际搜集情况登记出处；按角色职责逐步更新文档，完成后给出文件、变更、待决和下游交接。Git操作按本轮授权执行。

初始化包规定工作方式，不预设交易规则、类名、图形内容、测试数据或结果。实践产物在实际工作发生后建立。
